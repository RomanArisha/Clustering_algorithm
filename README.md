# Учебный проект: Кластеризация и её применение в задаче регрессии

## Описание
Данный проект выполнен в рамках курса по машинному обучению. Основная цель — изучить алгоритмы кластеризации и их применение для улучшения качества моделей регрессии на примере данных о ценах аренды жилья.

## Структура проекта
- `ML7.ipynb` — Jupyter Notebook с полным кодом и пояснениями.
- `data/train.json` — исходный датасет с объявлениями об аренде.
- `README.md` — описание проекта.

## Основные задачи
1. Реализация собственного алгоритма **K-средних** с различными методами инициализации центроидов:
   - Random — случайный выбор точек из данных
   - KMeans++ — вероятностный выбор, улучшающий сходимость
   - Maximin — максимизация минимального расстояния между центроидами
   - Random Partition — случайное разбиение с последующим вычислением центроидов

2. Сравнение реализованного KMeans с эталонной реализацией из `sklearn`.

3. Реализация собственного алгоритма **DBSCAN**

4. Сравнение реализованного DBSCAN с эталонной реализацией из `sklearn`

5. Реализация собственного алгоритма **Agglomerative Clustering** с различными методами вычисления расстояния между кластерами:
    - ward - расстояние Уорда
    - complete - расстояние "дальнего соседа"
    - single - расстояние "ближнего соседа"
    - average - среднее расстояние

6. Сравнение собственного алгоритма Agglomerative Clustering с эталонной реализацией из `sklearn`

7. Реализация собственного алгоритма **Gaussian Mixture**

8. Сравнение собственного алгоритма **Gaussian Mixture** с эталонной реализацией из `sklearn`

9. Кластеризация объектов по географическим координатам (широта/долгота) для выделения пространственных групп.

10. Использование меток кластеров как дополнительного признака в модели **Lasso** для предсказания цены аренды.

11. Анализ эффективности модели **Lasso** при использовании меток кластеров, а также итоговый коэффициент, который получили метки кластера

## Данные
Используется датасет с объявлениями о аренде жилья в Нью-Йорке, содержащий следующие основные поля:
- `bathrooms`, `bedrooms` — количество ванных комнат и спален
- `latitude`, `longitude` — географические координаты
- `price` — цена аренды (целевая переменная)
- `features` — список удобств (например, лифт, разрешение с животными)
- `interest_level` — уровень интереса к объявлению (низкий, средний, высокий)

Датасет предварительно обработан:
- Удалены выбросы по цене и координатам (1-й и 99-й процентили)
- Из поля `features` извлечены бинарные признаки (наличие конкретных удобств)
- Поле `created` преобразовано в компоненты даты (год, месяц, день)
- Категориальный признак `interest_level` закодирован с помощью One-Hot Encoding

## Регрессия
Для предсказания цены используется **Lasso-регрессия** с подбором гиперпараметра `alpha` через кросс-валидацию (`LassoCV`). В качестве признаков используются:
- все исходные признаки (кроме цены)
- дополнительный признак — метка кластера (нормализованная)

## Результаты
- Собственная реализация KMeans показала результаты, близкие к эталонной, а в некоторых метриках (силуэт, инерция) даже превзошла её.
- Добавление признака «метка кластера» улучшило качество предсказания цены: снизились MAE и RMSE, повысился R² по сравнению с моделью без этого признака.
- Реализованный DBSCAN корректно выделяет плотные кластеры и обрабатывает шум и по показателям силуэта близок к реализации `sklearn`

- Реализованный Agglomerative Clustering показал близкие результаты к эталонной, однако немного уступает
- Добавление признака «метка кластера» улучшило качество предсказания цены: снизились MAE и RMSE, повысился R² по сравнению с моделью без этого признака.
- Реализованный Gaussian Mixture показал результаты, не уступающие эталонной, на обучающей выборке, однако на тестовойвыборке коэффициент силуэта просел
